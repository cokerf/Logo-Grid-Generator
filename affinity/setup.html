Set up once. Run when you need it.

  1. Open the Script Editor

    In Affinity 3.3.3 or newer, open Window → Scripting → Script Editor and start an empty script.

  2. Paste the script

    Use the copy button above, select all in the editor and paste. Leave “Run as module” off: this script uses CommonJS.

  3. Open your logo, select it and run

    Open your logo SVG as a document first. Switch to Vector and select your curves, shapes, live text or logo group with the Move Tool. Focus the Script Editor and press F5 (Windows) or ⌘ Return (Mac), or click Run. Saving to the library alone does not run it. Try the controls with Preview on canvas enabled. Cancel removes the preview.

  4. Keep it in your library

    Save the script to your Scripts Library from the editor for reuse. Affinity can export a library category as .afscripts for importing on another machine.

Can’t select the .js file in Import Scripts?
That picker accepts Affinity’s .afscripts library files. This download contains JavaScript source: paste it into the Script Editor using the steps above. Renaming .js to .afscripts will not convert it.

Construction with purpose

Edges and curve peaks

Guides use real path endpoints and mathematical curve extrema. Nearby alignments merge to keep the drawing clear.

Fitted circles

Circle candidates must fit the surrounding arc. Duplicates merge; detail and maximum radius stay in your control.

Six colour palettes

Coordinated outlines, guides, circles, markers and optional backgrounds. Adjust each colour independently.

Editable layers

Outlines, handles, anchors, center marks, dimensions and grids sit together in one named construction container.

Before you begin

Requires desktop Affinity by Canva 3.3.3+ on Windows or macOS. Affinity Designer 2 does not support this scripting workflow.

The script reads exposed vector geometry and keeps source artwork editable. Image-only artwork and clipping or masking effects should use the web SVG workflow. Native execution and alignment still need checking inside Affinity Desktop.

For hatching, complex SVG imports, comparison and construction videos, use the web generator and bring its SVG export back into Affinity.

Troubleshooting

“require is not defined”
Turn off Run as module in the Script Editor settings.

The workspace says “No document open”
Open your logo SVG first, select the logo artwork and run again. The script adds construction to an existing document; it does not open or create a logo for you.

No construction appears
Select the actual logo artwork, rather than an earlier Logo Grid container. Enable Bézier outline first. Unsupported image-only layers have no native curve geometry.

Too much detail
Choose Essential guides and circle detail. Leave tangent spines and diagonal extensions off until you need them.

How do I remove a result?
Undo the operation, or delete its Logo Grid container. Your source artwork is preserved.
